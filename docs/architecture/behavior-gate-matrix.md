## Behavior Smoke

Run:

```sh
pnpm eval:behavior:smoke
```

This runs `krnBehaviorGate`, `sourceMapInvariants`, and
`typescriptBoundaryInvariants`, then the CLI run-readback/evidence behavior tests,
the brain-ranking and source-graph-ranking proxy evals, and Codex brief behavior fixture. Those cover the existing KRN behavior gate
test plus the V02-02 target trust exclusion case, the V03-01 target
fixture battle case, the V03-02 target owner-file-below-roots case, the V02-03
decorative source rejection case, the source artifact preview reuse case, the
V02-03 CLI run-readback proof/non-proof
guard, the V02-04 CLI memory feedback / anti-memory candidate guards, and the
brain-search usefulness mini-gate, the brain/source-graph ranking proxy fixtures, plus the V02-05 Codex brief / ContextROI
guards.

It is deterministic and does not call an LLM judge.

## Docs Lint

Run:

```sh
pnpm docs:lint
```

This runs focused harness invariants for active plan freshness, active context
hygiene, repo-local skill routability, source-to-decision skill contract, root
PLAN pattern-gate visibility, and matrix guard/proof boundaries through
`activePlanInvariants`, `contextHygieneInvariants`, `skillInvariants`, and
`behaviorGateMatrixInvariants`.

It is docs/proof-boundary lint, not behavior proof.

## Legacy Alias

`pnpm eval:krn:smoke` is the active proof route. The old eval alias was removed
after a green compatibility window so active scripts no longer preserve
eval-theater vocabulary.

## Promptfoo Boundary

Promptfoo remains a portable integration smoke/result adapter, not behavior
proof. It has no mandatory active script in the current verification gate.
Boundary fixtures and adapters must continue to stay non-authoritative via
`doesNotExecuteKrnBehavior=true`, and BehaviorFixture proof still requires
`krn_behavior_execution`.
